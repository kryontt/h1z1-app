03 / InstallAbout ten minutes plus the download

Four steps.
Then play.

01

Download

Get Setup.exe (1 MB). Windows may warn about an unknown publisher: choose More info → Run anyway.

02

Run Setup.exe

Pick the install folder; it needs about 18 GB free. Setup downloads the game, server and launcher into it, and resumes if the connection drops.

03

Requirements

Setup checks for Node.js, Git for Windows and Python 3. Anything missing installs with one click.

04

Press PLAY

The launcher opens by itself. Press PLAY, then in the game menu choose PLAY → TRAINING GROUND.

05 / FAQThe short answers

Before
you drop.

01Can I play with friends?

Not yet. The server runs on your own PC and the Training Ground is single player with bots. Multiplayer is the next big piece.

02Is this the real 2017 game?

The client is the real 0.0.134 build from September 2017. The server side is rebuilt from scratch, so some things are still missing. The Restored list above is what works today.

03Something looks broken. What do I check first?

Open the launcher's settings (the gear) and press Verify game files. It checks every file of the game against the known-good list and can repair damaged ones.

04Testing or Stable build?

Testing is the newest server build and gets the fixes first. Stable is the last build frozen as known good. Switch between them in the launcher settings; PLAY starts whichever is selected.

05Does it touch my Steam install?

No. It installs into its own folder and saves to %APPDATA%\2017KOTK. Steam and the live game are not involved.

06Is this official?

No. It's a fan project and has nothing to do with Daybreak Game Company.
