FAQ

Questions

Can I play with friends?

Not yet. The server runs on your own PC and the Training Ground is single player with bots. Multiplayer is the next big piece.

Is this the real 2017 game?

The client is the real 0.0.134 build from September 2017. The server side is rebuilt from scratch, so some things are still missing. The Restored list above is what works today.

Something looks broken. What do I check first?

Open the launcher's settings (the gear) and press Verify game files. It checks every file of the game against the known-good list and can repair damaged ones from the setup package.

Testing or Stable build?

Testing is the newest server build and gets the fixes first. Stable is the last build frozen as known good. Switch between them in the launcher settings; PLAY starts whichever is selected.

Does it touch my Steam install?

No. It installs into its own folder and saves to %APPDATA%\2017KOTK. Steam and the live game are not involved.
